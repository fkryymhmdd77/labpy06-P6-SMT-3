# Lab6Web — JavaScript DOM dan Event Handling
Tujuan

Memahami DOM, memilih dan memanipulasi elemen, menangani event dengan addEventListener(), serta membuat validasi form dan halaman interaktif.

Struktur File
lab6_dom_event/
├── index.html   # struktur halaman (Latihan 1–6, eksperimen, mini project)
├── style.css    # tampilan dan responsif
├── script.js    # seluruh logika JavaScript
└── README.md

Cara Menjalankan
Unduh/clone repository Lab6Web.
Buka index.html di browser modern (atau gunakan ekstensi Live Server di VS Code).
Buka Developer Tools (F12) untuk memeriksa Console.

Langkah Kerja
Latihan 1: mengubah teks judul dan paragraf dengan textContent.
Latihan 2: event click menampilkan waktu.
Latihan 3: classList.toggle() untuk gaya CSS.
Latihan 4: event input untuk penghitung karakter.
Latihan 5: validasi form (nama, email, usia) dengan preventDefault().
Latihan 6: to-do list dengan tombol selesai dan hapus.
Mini project: pendaftaran workshop (validasi, ringkasan langsung, reset).
